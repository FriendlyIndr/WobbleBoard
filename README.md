# WobbleBoard — Interactive Diagramming & Whiteboard Application

WobbleBoard is a browser-based visual workspace for creating diagrams and freeform drawings. Built with React and TypeScript, it explores interactive canvas rendering, geometric manipulation, and client-side state management.

### Key Engineering Highlights

-   **Interactive Canvas:** Built a freeform drawing workspace for creating and manipulating visual elements.

-   **Geometry & Rendering:** Integrated `rough.js` to generate hand-drawn, sketch-like visual styles.

-   **Element Manipulation:** Implemented interactive element editing and positioning within the canvas.

-   **State Management:** Managed canvas elements and drawing state within the React application.

-   **Persistence:** Implemented browser-side persistence using `localStorage` to retain workspace data.

-   **Frontend Architecture:** Built a component-based interface using React and TypeScript.

-   **Visual Editing Experience:** Explored the implementation of an Excalidraw-inspired drawing environment with a lightweight browser-native workflow.

### Tech Stack

`React` · `TypeScript` · `Rough.js` · `HTML Canvas` · `LocalStorage` · `Vite`
